# 🎬 IMDb Data Analysis & Prediction

## 📌 Project Overview

This project focuses on **Exploratory Data Analysis (EDA)** and **Machine Learning** on a movie and TV shows dataset.
The goal is to uncover patterns in content production, genres, and ratings, and to **predict IMDb scores** using a regression model.

---

## 🚀 Features

* Data Cleaning & Preprocessing
* Exploratory Data Analysis (EDA)
* Data Visualization using charts & graphs
* Machine Learning Model (Linear Regression)
* IMDb Score Prediction

---

## 📂 Dataset Description

The dataset contains information about movies and TV shows, including:

* Content Type (Movie / TV Show)
* Release Year
* Runtime
* Genres
* Production Countries
* IMDb Score
* TMDB Score
* Popularity

Only relevant columns were selected and cleaned for accurate analysis.

---

## 🛠️ Technologies Used

* Python 🐍
* Pandas & NumPy
* Matplotlib & Seaborn
* Scikit-learn

---

## 🔍 Methodology

### 1. Data Cleaning

* Removed missing values
* Filled incomplete fields
* Removed duplicates
* Selected useful features

### 2. Exploratory Data Analysis

* Movie vs TV show comparison
* Year-wise trend analysis
* Genre distribution
* Country-wise production analysis

### 3. Visualization

* Bar charts
* Line graphs
* Histograms

### 4. Machine Learning

* Model: Linear Regression

* Features used:

  * Release Year
  * Runtime
  * TMDB Popularity
  * TMDB Score

* Evaluation Metrics:

  * Mean Squared Error (MSE)
  * R² Score

---

## 📊 Key Insights

* Movies are more common than TV shows
* Content production increased after 2000
* Drama and Comedy are the most popular genres
* Most IMDb scores lie between **6–8**
* Only a few titles have very high popularity

---

## 🤖 Model Performance

The Linear Regression model showed **moderate accuracy**, indicating a relationship between popularity and IMDb ratings.
